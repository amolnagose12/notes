
GROUP BY : 	USED TO IDENTIFY UNIQUE VALUES OF THE GIVEN COLUMN(S) and also to PERFORM AGGREGATIONS.
			AGGREGATIONS LIKE: SUM, AVG, COUNT, MIN, MAX, RANK,......


HAVING : 	USED TO SPECIFY CONDITIONS ON GROUP BY DATA


ROLLUP : 	USED TO GENERATE NEW ROWS IN THE OUTPUT THAT CONTAINS VALUE LEVEL AGREGATIONS, IN GROUP BY.
						EX: 	COUNTRY WISE TOTAL POPULATION
							COUNTRY WISE, STATE WISE TOTAL POPULATION
							GRAND TOTAL POPULATION

CUBE   : 	USED TO GENERATE NEW ROWS IN THE OUTPUT THAT CONTAINS VALUE LEVEL AGGREGATIONS. FOR ALL POSSIBLE GROUP BY COLUMNS
						EX:	COUNTRY WISE TOTAL POPULATION
							COUNTRY WISE, STATE WISE TOTAL POPULATION
							GRAND TOTAL POPULATION
							STATE WISE TOTAL POPULATION 


GROUPING : 	USED TO IDENTIFY THE NEW ROWS RESULTED FROM ABOVE ROLLUP & CUBE.  
				1 MEANS NEW ROW AS A RESULT FROM ROLLUP or CUBE. 0 MEANS ORIGINAL ROW FROM TABLE
