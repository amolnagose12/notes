7. HOW TO INSTALL SQL SERVER?		OPTIONAL FOR OUR COURSE. WE HAVE 24 X 7 LIVE ONLINE SERVER.

		VERSION				SUPPORTED OPERATING SYSTEM					PROCESSOR TYPE
		--------------------------------------------------------------------------------------------------------------
		SQL SERVER 2019			WINDOWS 8 / 8.1 /  10	or	LINUX				64bit
		SQL SERVER 2017			WINDOWS 8 / 8.1 /  10	or	LINUX				64bit
		SQL SERVER 2016			WINDOWS 8 / 8.1 /  10						64bit
		SQL SERVER 2014			WINDOWS 7 / 8 / 8.1 /  10					32bit / 64bit
		SQL SERVER 2012			WINDOWS 7 / 8 / 8.1 /  10					32bit / 64bit
		

		SQL SERVER INSTALLATION PROCESS: 
		STEP 1: DOWNLOAD SQL SERVER SOFTWARE FROM : http://sqlschool.com/downloads/SQL-Server-Installation.html
		STEP 2: RIGHT CLICK THE DOWNLOADED FILE >  EXTRACT ALL. THEN YOU SEE A FOLDER WITH ALL FILES AND SUB FOLDERS FOR SETUP.
			DOUBLE CLICK @ "SETUP" APPLICATION FILE > THIS GIVES ONE WINDOW : "SQL SERVER INSTALLATION CENTER"
			INSTALLATION PAGE (LEFT SIDE) >> NEW INSTALLATION (RIGHT SIDE)  [2 : 1] > THIS GIVES SECOND WINDOW "SETUP SCREEN"
		STEP 3: SELECT "DEVELOPER" OR "EVALUATION" EDITION > ACCEPT LICENSING TERMS > SELECT "DATABASE ENGINE"
			SPECIFY "INSTANCE" NAME OR SELECT DEFAULT INSTANCE > ADD CURRENT USER. SELECT MIXED MODE AUTHENTICATION. SET sa PASSWORD.
		STEP 4: INSTALL


		INSTANCE	-	A SUCCESSFUL INSTALLATION OF SQL SERVER. UPTO 50 INSTANCES POSSIBLE PER OPERATING SYSTEM.
					TYPES OF INSTANCES:
						DEFAULT INSTANCE ***				NAMED INSTANCE
					------------------------------------------------------------------------------------------
						INSTANCE NAME = MSSQLSERVER			DEFINED DURING INSTALLATION
						SERVER NAME = COMPUTERNAME			SERVER NAME = COMPUTERNAME\INSTANCENAME
						CAN STORE UPTO 32767 DATABASES			CAN STORE UPTO 32767 DATABASES
						EACH DATABASE HAS UNLIMITTED TABLES		EACH DATABASE HAS UNLIMITTED TABLES
						PORT NUMBER FOR COMMUNICATION:1433		PORT NUMBER IS DYNAMICALLY ALLOCATED
						USED IN PRODUCTION ENVIRONMENT			USED IN DEVELOPER & TEST ENVIRONMENTS

					
MAIN GATE	SERVICE		-	A COMMUNICATION PATH BETWEEN OPERATING SYSTEM [WINDOWS or LINUX] AND SQL SERVER.
WATCHMEN	SERVICE ACCOUNT	-	OS LEVEL USER OR GROUP RESPONSIBLE TO MANAGE OR MONITOR THE ABOVE SERVICE. 

MAIN DOOR	AUTHENTICATION	-	A COMMUNICATION PATH BETWEEN SQL SERVER AND THE END USERS OR APPLICATIONS [APPS].
SECURITY	LOGIN		-	ANY USER USED TO CONNECT & USE SQL SERVER DATABASES. 

					TYPES OF AUTHENTICATION	:
					
					WINDOWS AUTHENTICATION	MODE				MIXED AUTHENTICATION  MODE
					-------------------------------------------------------------------------------------------
						ONLY WINDOWS USERS CAN CONNECT			ANY USER CAN CONNECT TO SQL SERVER
						DEFAULT OPTION					TO BE ACTIVATED MANUALLY
						ADMIN: CURRENT (ANY WINDOWS) USER		"sa" : SYSTEM ADMINISTRATOR ACCOUNT

		COLLATION	-	A SERVER PROPERTY USED TO SPECIFY THE LANGUAGE SETTINGS FOR DATA STORAGE. EX: ENGLISH, CHINESE
		
		FILESTREAM	-	A SERVER PROPERTY USED TO STORE BIG DATA & CLOUD DATA 



8. HOW TO INSTALL SSMS (SQL SERVER MANAGEMENT STUDIO) TOOL ?					APPLICABLE FOR WINDOWS OS ONLY.
			APPLICABLE FOR SQL SERVER 2016 & HIGHER VERSIONS ONLY.  FOR OLDER VERSIONS, THIS SSMS TOOL IS AUTO INSTALLED.

			***** TOOLS ARE GUI [GRAPHICAL USER INTERFACE] :  USED TO CONNECT, OPERATE WITH SQL SERVER. 
			EXAMPLE : CREATE DATABASE, STORE DATA, PROVIDE USER DATA ACCESS TO END USERS.
 
		STEP 1: DOWNLOAD SQL SERVER SOFTWARE FROM : http://sqlschool.com/downloads/SQL-Server-Tools.html
		STEP 2: DOUBLE CLICK @ "SSMS-SETUP-ENU" FILE > CLICK @ "INSTALL"
		STEP 3: RESTART YOUR COMPUTER. 



9. HOW TO TEST THE CONNECTIONS TO YOUR LOCAL SERVER ?
		STEP 1: GO TO WINDOWS OS > APPS > SEARCH > TYPE:  "SSMS" > THEN WE SEE SQL SERVER MANAGEMENT STUDIO IN THE APP LIST.
		STEP 2: CLICK @ SSMS APP > THIS PROMPTS FOR SERVER NAME
		STEP 3: UNDER SERVER NAME > BROWSE FOR MORE > EXPAND DATABASE ENGINE > SELECT REQUIRED SERVER (INSTANCE) > OK > CONNECT
