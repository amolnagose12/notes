
JOINS:  	A MECHANISM TO COMPARE TWO OR MORE TABLES & COMBINE THE RESULT INTO A SINGLE OUTPUT. 
PURPOSE : 	IN REAL-TIME, WE USE JOINS MAINLY FOR AUDITS, DATA REPORTING & BUSINESS ANALYSIS. 

Syntax:		SELECT * FROM  
			TABLE1     			-- LEFT   TABLE
			<JOIN TYPE>
			TABLE2				-- RIGHT  TABLE
			ON <JOIN CONDITION>

TYPES OF JOINS:	
1. INNER JOIN	:   USED TO COMPARE MULTIPLE TABLES, REPORT MATCHING DATA.		EX: COURSE WISE STUDENTS LIST
2. OUTER JOINS  :   USED TO COMPARE MULTIPLE TABLES, REPORT MATCHING & MISSING DATA	
	2.a - LEFT OUTER JOIN :		All Left Table Data + Matching Right Table Data. 	
								Non match Right table data is reported as null.
								EX: COURSES WITHOUT ANY STUDENTS
				 				  
	2.b - RIGHT OUTER JOIN :	All Right Table Data + Matching Left Table Data. 
								Non match Left table data is reported as null. 
								EX: STUDENTS WITH & WITHOUT ANY COURSES 
							 
	2.c - FULL OUTER JOIN :		Combined output of LEFT OUTER JOIN + RIGHT OUTER JOIN

3. CROSS JOIN	:	USED TO REPORT ALL POSSIBLE COMBINATIONS OF DATA. NO COMPARISONS. 	EX: YEAR WISE, QUARTER WISE SALES

JOIN OPTIONS:
4. MERGE JOIN	:   USED TO JOIN DATA FROM BIG TABLES FOR FASTER QUERY EXECUTION  - BY PERFORMING AUTO SORTING.   
					APPLICABLE FOR TABLES ABOVE 100k pages  

5. LOOP JOIN	:  	USED TO JOIN DATA FROM SMALL TABLES FOR FASTER JOINS.

6. HASH JOIN    :   USED TO JOIN DATA FROM ANY TABLES WITHOUT A PRIMARY KEY [HEAP TABLES]. 
					NO SORTING OPERATION TAKES PLACE.
